# SQL Student Database

A beginner-level SQL project demonstrating how to create a database and table, insert sample records, and retrieve information with queries.

## Topics covered
- `CREATE DATABASE` and `CREATE TABLE`
- Primary key and unique constraint
- `INSERT` and `SELECT`
- `WHERE` filtering
- `ORDER BY`
- `GROUP BY` and `COUNT`

## Run
Open `student_database.sql` in MySQL Workbench or another compatible SQL client and execute the statements.

The script uses sample data only.
